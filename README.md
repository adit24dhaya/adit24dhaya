## Featured work

### [PCB Defect Detection Capstone](https://github.com/adit24dhaya/Capstone_project)

Six-class visual-inspection workflow benchmarking YOLO11 and RT-DETR-L. The YOLO11l-1280 model reached 98.3% precision, 98.8% recall, and 0.99 mAP50 on the held-out test set. Includes ONNX export and a [live Gradio demo](https://adiivd-pcb-defect-detection.hf.space).

### [Real-Time Fraud & Transaction Risk Pipeline](https://github.com/adit24dhaya/fraud-risk-pipeline)

End-to-end fraud scoring on IEEE-CIS data: XGBoost inference over 175 aligned features, cost-based thresholding, Tree SHAP explanations, Evidently drift monitoring, FastAPI, Streamlit, and GitHub Actions CI.

### Smart Assembly Cell research

Physics-grounded smart-factory testbed in NVIDIA Isaac Sim with a TurtleBot3 transporter, four Franka Emika Panda arms, a simulated conveyor, lidar navigation, and telemetry-backed custody handoffs. I also developed ROS 2 coordination and an RL scheduling policy evaluated against a deterministic baseline.

### [Healthcare Agent System](https://github.com/adit24dhaya/healthcare-agent-system)

A Dockerized, four-agent healthcare decision-support platform with orchestration, retrieval, recommendation, explanation, safety guardrails, audit logging, and a tested REST API.

### [Stock Sentiment Trading System](https://github.com/adit24dhaya/Stock-Sentiment-Trading-with-News-Analysis)

BERT-driven financial-news sentiment pipeline for simulated trading decisions and historical backtesting, with persisted trade and performance artifacts.

### [Audio Anomaly Detection](https://github.com/adit24dhaya/audio_anomaly)

TensorFlow/Keras autoencoder workflow for industrial-fan anomaly detection using log-mel spectrogram features. Improved the detection workflow by 40% and reduced training time by 35% with CUDA acceleration.
